# 📝 Code Explanation

## 1️⃣ Analyze Text

User text input deta hai.

### Sample Input

```text
Python is easy to learn.
Python is powerful.
```

### Output

```text
Total Characters : 38
Total Words      : 7
Total Lines      : 2
```

**Explanation**

* `len(text)` → Characters count.
* `split()` → Words count.
* `splitlines()` → Lines count.

---

## 2️⃣ Analyze File

Program file read karta hai aur uska analysis dikhata hai.

### Sample File (`sample.txt`)

```text
Python is easy.
Python is fast.
Python is fun.
```

### Output

```text
File Analysis Report

Characters : 44
Words      : 9
Lines      : 3
```

**Explanation**

* File `"r"` mode mein open hoti hai.
* `read()` se data read hota hai.

---

## 3️⃣ Search Word

User kisi word ko search karta hai.

### Input

```text
Enter Word : Python
```

### Output

```text
Word Found : 3 Times
```

**Explanation**

Program `count()` function se occurrences count karta hai.

---

### Output
